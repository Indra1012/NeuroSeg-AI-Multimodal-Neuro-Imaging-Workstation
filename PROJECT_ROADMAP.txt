PROJECT OVERVIEW:
This project builds a medical image analysis and decision-support research prototype
for brain tumor segmentation from multimodal 3D MRI scans (T1, T1ce, T2, FLAIR). 
The core contribution integrates deep learning segmentation (4-channel U-Net), 
voxel-based tumor volume estimation ($cm^3$), Monte Carlo Dropout uncertainty 
quantification, controlled modality ablation experiments, and spatial error-uncertainty 
correlation analysis.

SYSTEM POSITIONING & TERMINOLOGY:
> "A medical image analysis and decision-support research prototype."
Note: The system performs automated brain tumor mask prediction, quantitative volume 
estimation, and model confidence mapping. It is NOT an independent diagnostic 
system nor a clinical cancer staging tool.

FEASIBILITY & SCOPE VERDICT: 
[YES - 100% DOABLE & HIGHLY RIGOROUS]
The scope is divided into three distinct layers:
1. Core ML System: 4-channel input (T1+T1ce+T2+FLAIR) -> Patient-level split -> Preprocessing -> U-Net -> Tumor Segmentation.
2. Useful Quantitative Outputs: Predicted Mask -> Dice/IoU/Precision/Recall -> Physical Voxel Tumor Volume ($cm^3$) -> MC Dropout Uncertainty Map.
3. Research & Experimental Contribution: Modality Ablation (FLAIR vs T1+FLAIR vs T1+T2+FLAIR vs All 4) -> Uncertainty vs Error Correlation.

🟢 PHASE 2 — Dataset Acquisition & Multimodal MRI Fundamentals
[SATURDAY REVIEW TARGET]
Goal: Acquire medical MRI data (e.g., BraTS Dataset) and establish dataset conventions.
  - 2.1 Download BraTS / Brain Tumor MRI dataset in NIfTI format (.nii / .nii.gz).
  - 2.2 Understanding 4 MRI Modalities:
        * T1-weighted (T1): Anatomical structure overview.
        * T1-Contrast Enhanced (T1ce): Highlights Gd-contrast enhancement; shows active vascular tumor borders.
        * T2-weighted (T2): Highlights fluid signals & edema.
        * FLAIR (Fluid Attenuated Inversion Recovery): Suppresses CSF fluid signal; highlights peritumoral edema clearly.
  - 2.3 Ground-Truth Mask Annotations:
        * Label 0: Background / Non-brain
        * Label 1: Necrotic and non-enhancing tumor core (NCR/NET)
        * Label 2: Peritumoral edema (ED)
        * Label 4: Enhancing tumor (ET)
        * Whole Tumor Target (WT): Merged binary target (Labels 1 + 2 + 4) vs Background.
  - 2.4 NIfTI Metadata & Spatial Coordinates (Affine matrices, header metadata, voxel spacing in mm).

🟢 PHASE 4 — Medical MRI Preprocessing & Intensity Normalization
[SATURDAY REVIEW TARGET]
Goal: Standardize MRI pixel intensities and spatial dimensions for neural network input.
  - 4.1 Skull Stripping / Brain Masking (Ensuring background non-brain tissue is zeroed out).
  - 4.2 Spatial Resampling & Cropping/Padding (Standardizing axial slices to 256x256).
  - 4.3 Intensity Clipping (Clipping extreme intensity outliers between 1st and 99th percentiles).
  - 4.4 Intensity Normalization:
        * Z-score normalization per patient/modality over non-zero brain voxels: (x - mean) / std.

🟢 PHASE 5 — Data Augmentation & Patient-Level Splitting
[SATURDAY REVIEW TARGET]
Goal: Ensure strict patient-level separation and data diversity.
  - 5.1 Patient-Level Data Splitting:
        * Split train (70%), val (15%), test (15%) STRICTLY AT THE PATIENT LEVEL to prevent slice leakage across splits.
  - 5.2 Configure synchronized `Albumentations` transforms (applied identically to all 4 MRI modalities and ground-truth mask):
        * Random Horizontal/Vertical Flipping, Slight Rotation (-15° to +15°), Elastic Deformations.

🟢 PHASE 6 — Multimodal 4-Channel Input Tensor & PyTorch DataLoader
[SATURDAY REVIEW TARGET]
Goal: Combine 4 MRI modalities into a 4-channel input representation.
  - 6.1 Tensor Stacking: Stack [T1, T1ce, T2, FLAIR] slices into shape `(4, 256, 256)`.
  - 6.2 PyTorch `Dataset` Class (`BrainTumorDataset`): Dynamic loading of 4-channel MRI arrays and target masks.
  - 6.3 PyTorch `DataLoader` setup with multi-processing workers, batching (batch_size = 16/32), and shuffling.

🟢 PHASE 7 — U-Net Model Architecture & Combined Loss Function
[SATURDAY REVIEW TARGET]
Goal: Build 4-channel U-Net and establish optimization loss.
  - 7.1 PyTorch U-Net Architecture Implementation:
        * Encoder (Contracting Path): 4 -> 64 -> 128 -> 256 -> 512 channels (Conv2D -> BatchNorm -> ReLU -> MaxPool2D).
        * Bottleneck: 512 -> 1024 channels.
        * Decoder (Expanding Path): 1024 -> 512 -> 256 -> 128 -> 64 channels (UpSampling -> Skip Connection Concatenation -> Conv2D).
        * Output Layer: 1x1 Conv2D + Sigmoid activation for binary mask output.
  - 7.2 Combined Loss Function Implementation:
        * `Total_Loss = BCE_Loss + Dice_Loss` (balances pixel-wise probability with spatial overlap optimization).
  - 7.3 Verification: Synthetic batch forward pass test `(Batch, 4, 256, 256)` -> `(Batch, 1, 256, 256)`.

🟢 PHASE 10 — Quantitative Evaluation Suite
[CORE POST-REVIEW]
Goal: Measure segmentation accuracy using standard medical metrics.
  - 10.1 Dice Similarity Coefficient (DSC): Measure spatial overlap ($2|P \cap G| / (|P| + |G|)$).
  - 10.2 Intersection over Union (IoU / Jaccard Index): $|P \cap G| / |P \cup G|$.
  - 10.3 Precision & Recall (Sensitivity).
  - 10.4 Automated metric evaluation script generating summary CSV reports (Mean, Std Dev).

🟢 PHASE 11 — Quantitative Tumor Volume Estimation Engine
[CORE POST-REVIEW]
Goal: Compute physical tumor volume in cubic centimeters ($cm^3$) from 3D NIfTI metadata.
  - 11.1 Extract voxel spacing dimensions ($dx, dy, dz$) in mm from NIfTI header affine.
  - 11.2 Single voxel volume: $V_{\text{voxel}} = dx \times dy \times dz$ ($mm^3$).
  - 11.3 Calculate Total Volume: $\text{Volume } (cm^3) = (\text{Tumor Voxel Count} \times V_{\text{voxel}}) / 1000$.
  - 11.4 Volume Error Analysis: Ground-Truth volume vs Predicted volume (Absolute & Relative Error %).

🟢 PHASE 12 — Monte Carlo Dropout Uncertainty Mapping
